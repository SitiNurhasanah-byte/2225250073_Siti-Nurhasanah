# 02 — Desain Pembelajaran (Tahap *Design* ADDIE)

## 1. Capaian & Tujuan Pembelajaran

**Capaian Pembelajaran (Fase D, elemen Aljabar — ringkasan):** peserta didik dapat memahami relasi
dan fungsi, serta menyajikan, menganalisis, dan menggunakan fungsi linear dan persamaan garis lurus
(dalam bentuk tabel, grafik, dan persamaan) untuk menyelesaikan masalah.

> Cocokkan redaksi dengan dokumen CP resmi terbaru yang berlaku di sekolah uji coba.

### Tujuan Pembelajaran (TP)

| TP | Siswa dapat… | Level kognitif | Modul |
|---|---|---|---|
| TP1 | menentukan dan menggambar titik koordinat (x, y) pada bidang Cartesius | C3 | M1 |
| TP2 | menghitung nilai y dari persamaan `y = mx + c` untuk x tertentu dan menyusun tabel nilai | C3 | M2 |
| TP3 | menggambar grafik garis lurus dari persamaannya | C3 | M2 |
| TP4 | menjelaskan makna gradien (m) dan konstanta (c) pada `y = mx + c` | C2 | M3 |
| TP5 | menentukan gradien dari persamaan, dari dua titik, dan dari grafik | C3 | M3, M4 |
| TP6 | menentukan persamaan garis melalui satu titik dengan gradien tertentu dan melalui dua titik | C3 | M5 |
| TP7 | menganalisis hubungan gradien garis sejajar dan tegak lurus | C4 | M5 |
| TP8 | menyelesaikan soal cerita kontekstual yang berkaitan dengan PGL | C4 | M6 |

Urutan modul mengikuti prinsip **simple-to-complex sequencing** untuk mengendalikan beban intrinsik:
titik → substitusi → grafik → gradien → persamaan → aplikasi.

## 2. Prinsip Cognitive Load yang Diterapkan

| Efek/Prinsip CLT | Penerapan di GarisKu | Temuan pendukung |
|---|---|---|
| **Worked-example effect** | Setiap konsep diawali contoh soal yang dibahas langkah demi langkah | GL01, DS01 |
| **Completion-problem / fading** | Latihan 1 hampir lengkap → latihan 2 setengah → latihan 3 mandiri | DS02, IL01 |
| **Split-attention** | Persamaan, tabel, dan grafik dalam satu layar dan saling ter-highlight | EL02, IL02 |
| **Modality** | Video/narasi untuk penjelasan grafik (opsional), bukan teks panjang di atas grafik | GL03 |
| **Redundancy** | Tidak mengulang teks yang sama dalam bentuk narasi + teks + gambar sekaligus | EL01 |
| **Segmenting & learner pacing** | Kartu pendek, tombol Lanjut/Ulang, tanpa auto-advance | EL04 |
| **Pre-training** | Glosarium istilah (absis, ordinat, gradien, konstanta) dikenalkan sebelum dipakai | K03 |
| **Coherence** | Tanpa dekorasi, musik, atau warna yang tidak menyampaikan makna | DS03 |
| **Signaling** | Highlight warna aksen hanya pada bagian yang sedang dibahas | EL02 |
| **Variability** | Variasi bentuk soal dengan label "Konsep sama: …" | IL04 |
| **Self-explanation** (GL) | Prompt "Mengapa langkah ini?" dengan pilihan alasan | GL04 |
| **Expertise reversal** | Siswa yang benar 3× berturut-turut dapat melewati contoh dan petunjuk otomatis disembunyikan | — |

## 3. Pola Alur Tiap Modul (Template)

```
1. Pemanasan (1 soal cek prasyarat, 30 detik)            → aktifkan pengetahuan awal
2. Kartu Konsep (3–6 kartu, ≤ 3 kalimat + 1 visual)      → segmenting
3. Eksplorasi di Lab Garis (tugas terarah 1–2)           → pengalaman visual
4. Contoh Soal A (penuh, langkah demi langkah)           → worked example
5. Soal B (melengkapi langkah yang dikosongkan)          → completion problem
6. Latihan C–E (fading; petunjuk 3 tingkat; umpan balik) → praktik
7. Variasi bentuk (1–2 soal "konsep sama, bentuk beda")  → transfer (IL04)
8. Jelaskan Caramu (1 prompt)                            → germane load
9. Skala mental effort (1–9)                             → data CLT
10. Ringkasan modul (3 poin + "yang perlu diulang")       → konsolidasi
```

Durasi target per modul: **15–20 menit** (cocok untuk 1 JP sisa waktu atau tugas rumah).

## 4. Desain Petunjuk Bertingkat (Scaffolding)

| Tingkat | Isi | Contoh (Bank Soal 3c: y = 2x − 1, berapa y jika x = 5?) |
|---|---|---|
| Petunjuk 1 — Pengingat konsep | Konsep/rumus yang relevan | "Ganti x dengan 5 pada persamaan." |
| Petunjuk 2 — Langkah pertama | Menuliskan langkah awal | "y = 2 × 5 − 1. Hitung perkaliannya dulu." |
| Petunjuk 3 — Contoh serupa | Soal mirip yang sudah selesai | "Jika x = 3: y = 2 × 3 − 1 = 6 − 1 = 5." |
| Pembahasan | Penyelesaian penuh | Muncul setelah 2× salah atau dipilih siswa |

Penggunaan petunjuk **tidak mengurangi skor secara kasar**; hanya dicatat untuk rekap dan penelitian
(agar siswa tidak takut meminta bantuan — GL02).

## 5. Desain Umpan Balik

| Jenis | Kapan | Contoh |
|---|---|---|
| Konfirmasi | Benar | "✓ Benar! (5, 9) ada di garis y = 2x − 1." |
| Diagnostik | Salah, pola miskonsepsi dikenali | "Hasilmu 8. Sepertinya kamu menghitung 2 × (5 − 1). Ingat: kalikan dulu, baru kurangi." |
| Umum | Salah, pola tidak dikenali | "Belum tepat. Coba cek lagi langkah perkalian, atau buka Petunjuk 1." |
| Elaboratif | Setelah benar (sesekali) | "Perhatikan: setiap x naik 1, y naik 2. Itulah arti gradien 2." |

Nada: ramah, singkat, tanpa menyalahkan. Satu umpan balik maksimal 2 kalimat.

## 6. Strategi Asesmen

| Asesmen | Bentuk | Tujuan |
|---|---|---|
| Diagnostik (pretest) | BS-1 s.d. BS-4, uraian di kertas, tanpa petunjuk | Mathematical Literacy awal; data N-gain |
| Formatif | Latihan tiap modul (BS-1 s.d. BS-4 + LT) di aplikasi | Umpan balik & penyesuaian |
| Sumatif (posttest) | PT-1 s.d. PT-4 (paralel BS), uraian di kertas | Data N-gain |
| Beban kognitif | Skala Paas (1–9) per set latihan + angket CLT (lihat docs/07) | Mengukur T2 |

Kisi-kisi instrumen Mathematical Literacy (lengkap di `docs/10-bank-soal.md` §2). Satu soal untuk
setiap proses matematis:

| No | Indikator (proses) | Pretest | Posttest (paralel) | TP | Skor maks |
|---|---|---|---|---|---|
| 1 | Mathematical Reasoning | BS-1 Sewa sepeda | PT-1 Tarif ojek | TP2, TP8 | 6 |
| 2 | Formulating Situations Mathematically | BS-2 Fotokopi | PT-2 Cetak foto | TP5, TP6, TP8 | 6 |
| 3 | Employing Concepts, Facts, and Procedures | BS-3 Garis pada peta | PT-3 Kabel pada denah | TP2, TP5, TP6 | 6 |
| 4 | Interpreting, Applying, and Evaluating Outcomes | BS-4 Tabungan | PT-4 Bak air | TP2, TP8 | 6 |
| | | | | **Total** | **24** |

Nilai = (skor / 24) × 100. TP1, TP3, TP4, dan TP7 tidak diukur oleh instrumen penelitian. Tujuan ini
dilatih dan dinilai secara formatif lewat soal LT-M1-1 s.d. LT-M3-2 di aplikasi.

## 7. Pemetaan Temuan → Keputusan Desain

| Temuan | Keputusan |
|---|---|
| IL02 titik koordinat | Modul M1 khusus titik; mode "Plot titik" dengan umpan balik tukar x–y |
| IL03 lupa operasi | Isian bertahap; substitusi ditulis eksplisit `2 × (3) + 1` |
| IL05 & DS02 gradien | Modul gradien dipecah menjadi 2 (M3 makna, M4 menghitung); segitiga Δy/Δx animatif atas ketukan siswa |
| IL04 transfer | Label "Konsep sama" + perbandingan dua soal berdampingan |
| EL04 tempo | Tidak ada timer di latihan; waktu dicatat diam-diam hanya untuk penelitian |
| EL05 soal cerita | M6 dengan alat tandai "Diketahui/Ditanya" |
| GL03 video | Video 1–3 menit per modul, opsional |
| DS03 tampilan | Design system minimalis (docs/04) |
